四、品类分析（目标占比拆解 / 结构达成）
大类目标 = 该店区间营收目标 × 大类目标占比（织物 55% / 鞋靴 15% / 包袋&皮革 10% / 家居 8% / 茉莉管家 12%，合计 100%）。
品类目标 = 大类目标 × 类内目标占比（织物 75/20/5；鞋靴 70/20/8/2；包袋&皮革 80/10/10）。家居、茉莉管家无细分，只到大类一层。
缺口 = 目标金额 − 实际实收金额，正数为未达成；实际件数 / 实收取自「品类」表（按“品类-规整后”归并）。
「包袋&皮革-奢洗」与「茉莉管家」在「品类」表中暂无数据，其缺口等于整块目标，属数据待补项，不代表真实亏损；合计行另给出「剔除无数据项」的考核口径缺口。

指标口径

  1. 营收＝新数据源「营收」列（= 营业额 + 70%×券消费），与数据源「实际营收」列同口径（实收 + 70%×券抵扣）。
  2. 现金流＝「新数据源」现金流列（门店现金流入：卡项充值/售卡 + 现金/微信/支付宝直接收款）。上年同期及 2026 年历史月份取「数据源」D 列（充值/售卡/退卡）+ 非储值方式实收，保持同口径。客户情况（新客/临转会/续充/升级/降级/退卡）取「卡项流水」，已剔除卡项名称「物业尊享卡」「国色伙伴卡」。
  3. 新客＝本月「办卡」且手机号在「数据源」（2021-06 至 2026-09 历史消费）中无消费记录；临转会＝本月办卡且历史有消费记录（跨门店判定）。
  4. 续充 / 升级 / 降级 / 退卡＝卡项流水「业务类型」原值归类。
  5. 客户数＝日去重客户数之和（同一客户当日多次消费计1人，跨日重复计人/次）；客单价＝营收÷客户数；件单价＝营收÷衣物件数；连带率＝衣物件数÷客户数。
  6. 券消费占比＝券消费÷（券消费＋营业额）。
  7. 目标＝「日目标」表逐日营收/现金流目标，区间目标为所选日期目标之和；整月目标为31天之和（重庆公司：营收 286,000 / 现金流 105,000）。
